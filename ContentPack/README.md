# AudioVisualizer Open Content Pack (MIT / CC0)

All shaders, scripts, WebAssembly modules, 3D glTF models, and presets inside `ContentPack/` are released under the **CC0 1.0 Universal / MIT License** so you can freely use, remix, and redistribute them in commercial or open-source shows.

## Contents
- `Shaders/ISF_Audio_HyperTunnel.fs`: Interactive Shader Format (ISF 2.0) audio-reactive tunnel shader.
- `Shaders/Shadertoy_Neon_Rings.glsl`: Shadertoy-compatible (`mainImage`) spectrum ring shader with feedback.
- `Scripts/bouncy_follower.avscript`: Stateful Luau/Lua-style node graph script.
- `Scripts/wave_folder.wasm`: Compiled WebAssembly binary module exporting `process(x, y, time, a, b) -> f32`.
- `Models/octahedron.gltf`: Self-contained glTF 2.0 crystal mesh for instanced 3D rendering.
